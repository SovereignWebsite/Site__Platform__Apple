Scope 1

The models, and Private Cloud Compute

On this page

  • On-device model
  • Server model
  • Private Cloud Compute

Apple's model descriptions we could read are from 2024 and 2025. We found no Apple page giving the size of the 2026 models, so for those this guide says not stated.

On-device model

In June 2024 Apple described a "~3 billion parameter on-device language model".[5] Its July 2025 report describes a "~3B-parameter on-device model optimized for Apple silicon through architectural innovations such as KV-cache sharing and 2-bit quantization-aware training".[6]

Server model

The 2025 report describes "a scalable server model built on a novel Parallel-Track Mixture-of-Experts (PT-MoE) transformer", for Apple's Private Cloud Compute platform. Its parameter count: not stated.[6] The 2024 post says the server model runs on Apple silicon servers with Private Cloud Compute.[5]

Languages the models support: the 2025 report says "multilingual, multimodal" and "several additional languages" without listing them.[6] For the languages of the features, see Apple Intelligence.

Private Cloud Compute

Apple's security blog (June 2024) describes what it says Private Cloud Compute does:[4]

  • It runs on custom Apple silicon nodes using "a hardened subset of the foundations of iOS and macOS".
  • The device encrypts the request "directly to the public keys of the PCC nodes" it has confirmed are valid. Load balancers and privacy gateways sit outside that trust boundary and do not have the keys.
  • A third-party relay hides the device's source IP address.
  • "User data is never available to Apple, even to staff with administrative access", and is "not retained in any form after the response is returned".
  • There is no remote shell and no general-purpose logging. Only pre-specified, structured and audited logs and metrics can leave a node.

For outside checking, the post says Apple would make software images of every production build "publicly available for security research", keep a transparency log, and provide a virtual research environment that runs a node on a Mac with Apple silicon. That post is written in the future tense, so this guide does not say those were all delivered: not stated.[4]

On training data, Apple says it does not use users' private personal data or interactions to train its foundation models unless they explicitly choose to help improve them.[5]
