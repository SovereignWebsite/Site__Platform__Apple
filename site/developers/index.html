Scope 1

For developers: the Foundation Models framework

On this page

  • What it offers
  • Cost and limits
  • Other things an app can plug into
  • What Apple's pages do not say

Apple calls it "a native Swift API that gives you direct access to Apple Foundation Models, on device and in Private Cloud Compute".[7] It is also described as the way to reach "the same on-device model that powers Apple Intelligence".[9]

What it offers

  • Named capabilities: guided generation, tool calling, image understanding and Dynamic Profiles.[8]
  • Dynamic Profiles are "declarative APIs for continuously updating your session's model, tools, and instructions on the fly". Each profile has its own model, temperature, reasoning level and toolset, and the session transcript is shared across switches.[8]
  • On device, apps can "work without internet connectivity".[8]
  • It can work with other models: Apple lists Core AI, MLX, Claude and Gemini providers, each linked to a GitHub repository.[8]
  • Also named: an Evaluations framework, an fm command line tool in macOS 27 and a Python SDK.[7][8]
  • Vision tools such as text recognition and barcode reading are described as on-device.[9]

Cost and limits

  • Developers in the small business programme with fewer than 2 million first-time downloads can use Apple Foundation Models on Private Cloud Compute "at no cloud API cost".[7][8]
  • Some server-side features have daily usage limits, and expanded access "will be available for a fee in the future". The fee: not stated.[8]
  • Apple says users' data in Private Cloud Compute "is not stored or accessible to Apple or anyone else".[8]

Other things an app can plug into

Apple's developer page also names App Intents, Image Playground, Shortcuts, Visual Intelligence, Write with Siri and Genmoji.[7] Image Playground images are "generated on Private Cloud Compute, so photos are never stored or shared".[7]

What Apple's pages do not say

The minimum operating system version, the device requirements for the framework, how to check whether the model is available, class names and code samples: not stated. The framework's documentation page returned only its title when we read it, so we have not copied any code from it.
