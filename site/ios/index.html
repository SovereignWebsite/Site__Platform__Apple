Distribution and the developer account

  • Apple lists App Store distribution, alternative distribution "in certain regions", and Developer ID with notarisation for Mac apps outside the Mac App Store.[13]
  • The Apple Developer Program is shown as a "$99 annual membership" (US page), with an Enterprise Program at "$299/year" for private distribution to employees.[14] Prices in other countries: not stated.
  • A free Apple developer account gives beta Xcode and operating systems, device testing, forums and Feedback Assistant. Membership adds TestFlight and App Store distribution.[14]

TestFlight

  • Up to 100 builds can be shared.[11]
  • Internal testers: up to 100 members of your team in certain roles. External testers: up to 10,000, by email invite or public link. A tester can use builds on up to 30 devices.[11]
  • The first build for external testing must be approved by App Review for TestFlight.[11]
  • A build can be tested for up to 90 days, and the TestFlight app is free. These two points come from a summary, so check the page.[12]

On-device machine learning

Apple's machine learning page names Core AI, the Foundation Models framework, Vision, Speech, Core ML, Metal and MLX.[10]

  • Core AI is "designed to be the best way to bring and run AI models on device", with "zero server dependencies and zero token costs".[10]
  • Core ML gives "fast performance for integrating traditional machine learning models", with Core ML Tools for conversion. For large language models and other generative models Apple points to Core AI.[10]
  • MLX is an open-source array framework.[10]
  • Core ML's own documentation page returned only its title, so details beyond this: not stated.

iCloud and CloudKit

  • Apple says CloudKit gives "up to 1PB of storage for your app's public data", and private data is stored in the users' own iCloud accounts.[15]
  • It names automatic syncing, encrypted fields and the CloudKit Console.[15]
  • Whether it needs a paid membership: not stated. Its documentation page returned only its title.

Privacy rules for apps

  • Developers must give privacy practice information in App Store Connect to submit new apps and updates, and a privacy policy link is required.[16]
  • The App Review Guidelines section on privacy (5.1) covers data collection and storage, data use and sharing, health data, kids and location. As summarised for us: personal data may not be used or shared without permission, tracking needs the App Tracking Transparency APIs, and kids' apps should not include third-party analytics or advertising.[17] Read the guidelines before relying on these.
  • Privacy manifests: not stated (the page returned only its title).
